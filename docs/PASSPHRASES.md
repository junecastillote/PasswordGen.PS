# Passphrase Generation

`New-PGenRandomPassphrase` generates cryptographically secure passphrases using the EFF Large Word List included with PasswordGen.PS.

Unlike traditional passwords that rely on complex character combinations, passphrases use multiple randomly selected words to provide strong security while remaining easier to read, type, and remember.

---

## How It Works

Passphrases are generated by:

1. Loading the EFF Large Word List during module import.
2. Selecting random words using `System.Security.Cryptography.RandomNumberGenerator`.
3. Preventing duplicate words within a single passphrase.
4. Combining selected words using the specified separator.
5. Optionally capitalizing words.
6. Optionally appending a randomly generated numeric suffix to one randomly selected word.

Example:

```powershell
New-PGenRandomPassphrase
```

Output:

```text
grudge-smuggler-symphonic-squeegee
```

---

## Why Use Passphrases?

Passphrases provide several advantages:

- Easier to remember
- Easier to type
- Easier to read
- Strong cryptographic randomness
- Less prone to transcription mistakes
- Suitable for human-created credentials

Example:

```text
Grudge-Smuggler-Symphonic-Squeegee
```

is generally easier to work with than:

```text
T7!v#Nk2@pQ6Lm$R
```

while still providing strong security when generated from a sufficiently large word list.

---

## EFF Large Word List

PasswordGen.PS uses the EFF Large Word List.

Characteristics:

- 7,776 words
- Curated for passphrase generation
- Suitable for Diceware-style passphrases
- Loaded once during module import
- Works completely offline

Metadata output reports:

```text
WordListSource : EFF Large Word List
WordListSize   : 7776
```

---

## Entropy

Entropy represents the theoretical search space of a generated passphrase.

PasswordGen.PS estimates entropy using:

```text
WordCount × log₂(WordListSize)
```

For a 7,776-word list, approximate values are:

| Words | Estimated Entropy |
| ----- | ----------------: |
| 3     |        38.75 bits |
| 4     |        51.70 bits |
| 5     |        64.62 bits |
| 6     |        77.55 bits |
| 7     |        90.47 bits |
| 8     |       103.40 bits |

Adding a numeric suffix increases entropy further.

## Default Behavior

```powershell
New-PGenRandomPassphrase
```

Default settings:

```text
WordCount = 4
Separator = "-"
CapitalizeWords = False
AddNumber = False
```

Example:

```text
grudge-smuggler-symphonic-squeegee
```

---

## Specifying Word Count

Generate a longer passphrase:

```powershell
New-PGenRandomPassphrase -WordCount 6
```

Example:

```text
grudge-smuggler-symphonic-squeegee-reward-unify
```

Generate a shorter passphrase:

```powershell
New-PGenRandomPassphrase -WordCount 3
```

Example:

```text
grudge-smuggler-symphonic
```

---

## Custom Separators

The default separator is:

```text
-
```

You can choose any separator.

### Underscore

```powershell
New-PGenRandomPassphrase -Separator '_'
```

Example:

```text
grudge_smuggler_symphonic_squeegee
```

### Period

```powershell
New-PGenRandomPassphrase -Separator '.'
```

Example:

```text
grudge.smuggler.symphonic.squeegee
```

### At Sign

```powershell
New-PGenRandomPassphrase -Separator '@'
```

Example:

```text
grudge@smuggler@symphonic@squeegee
```

---

## Capitalizing Words

Use `-CapitalizeWords` to convert each word to title case.

```powershell
New-PGenRandomPassphrase `
    -CapitalizeWords
```

Example:

```text
Grudge-Smuggler-Symphonic-Squeegee
```

---

## Numeric Suffixes

Use `-AddNumber` to append a randomly generated numeric value to one randomly selected word.

```powershell
New-PGenRandomPassphrase `
    -AddNumber
```

Example:

```text
Grudge36-Smuggler-Symphonic-Squeegee
```

The target word is selected randomly.

Examples:

```text
Grudge36-Smuggler-Symphonic-Squeegee
```

```text
Grudge-Smuggler36-Symphonic-Squeegee
```

```text
Grudge-Smuggler-Symphonic36-Squeegee
```

```text
Grudge-Smuggler-Symphonic-Squeegee36
```

### Specify Number Length

```powershell
New-PGenRandomPassphrase `
    -AddNumber `
    -NumberLength 4
```

Example:

```text
Grudge4821-Smuggler-Symphonic-Squeegee
```

---

## Metadata Output

Use `-PassThruObject` to return metadata about the generated passphrase.

```powershell
New-PGenRandomPassphrase `
    -AddNumber `
    -CapitalizeWords `
    -PassThruObject
```

Example:

```text
Passphrase           : Grudge36-Smuggler-Symphonic-Squeegee
Length               : 36
WordCount            : 4
Words                : {Grudge, Smuggler, Symphonic, Squeegee}
PassphraseParts      : {Grudge36, Smuggler, Symphonic, Squeegee}
Separator            : -
WordsCapitalized     : True
NumberAdded          : True
NumberLength         : 2
NumberValue          : 36
NumberWordIndex      : 0
NumberWordPosition   : 1
WordListSize         : 7776
WordListSource       : EFF Large Word List
EstimatedEntropyBits : 58.34
CopiedToClipboard    : False
```

## Clipboard Support

Copy the generated passphrase to the clipboard:

```powershell
New-PGenRandomPassphrase `
    -CopyToClipboard
```

The passphrase is still returned to the pipeline.

---

## SecureString Output

Return a SecureString instead of plaintext:

```powershell
New-PGenRandomPassphrase `
    -AsSecureString
```

Output type:

```text
System.Security.SecureString
```

## Notes

### No Repeated Words

Words are selected without replacement.

Example:

```text
grudge-smuggler-grudge-squeegee
```

will never be generated.
